## Dataset Aggregation and Processing

This repository contains the dataset aggregation and preprocessing code used in the Master’s thesis:

**_Scaling Synthetic Annotations for Fine-Tuning Language Models for Media Bias Classification_**


## Repository Structure

- Within each dataset folder, the Jupyter notebook  
  **`create_dataset.ipynb`**  
  contains all preprocessing steps required to construct and save the final dataset used in the experiments.
- Instructions for creating the **unlabeled TGDataset** are provided in the **`telegram/`** directory.
